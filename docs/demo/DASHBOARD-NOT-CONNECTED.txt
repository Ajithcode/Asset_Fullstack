Visible Dashboard pages (sidebar.ts:95-100): IoT & Tracking Overview, Asset Overview.

Service = FE services/dashboard/dashboard.ts.  /ad = /api/asset-dashboard (Asset service, BE Endpoints/AssetDashboardEndpoints.cs)

Source legend:
  REAL API      = values come from a backend route (REAL-EMPTY in DEMO-AUDIT = wired, but dev DB has no data -> "No data available")
  HARDCODED LIST= options/labels from a constant in the frontend
  MOCK          = invented numbers in the frontend (none left on the 2 visible pages)
  DISABLED      = control shown but not usable
  NO API        = no backend exists; placeholder shown
  UI-ONLY       = filter/toggle changes the view client-side only, no request parameter

Filter effect column: API = selecting changes the request (param named); CLIENT = filters data already loaded in the browser;
                      NONE = selection has no effect on this item.

3) MOCK DATA

NOT CONNECTED
=============
Everything that is not "REAL API with the filters sent to the API":

NO API / DISABLED
 1. Asset Overview - KPI Lifecycle Value: NO API (placeholder "–"). Needs a lifecycle/book-value endpoint.
 2. Asset Overview - "As of" 30 Days Ago / 90 Days Ago: DISABLED. Needs a portfolio history/snapshot API.
 3. Asset Overview - "As of Today": only option; no request parameter (cosmetic).
 4. Quick Actions on both pages: navigation buttons only (no data, by design).

HARDCODED OPTION LISTS (options not from an API)
 5. IoT - Period 7/30/90: html:14 (BE GET /ad/filters returns the same days but is never called).
 6. IoT - Timeline period 7/30/90: html:179.
 7. IoT - Status Online/Idle/Offline/Unknown: iot-overview-data.ts:39 (selection IS sent as status=).
 8. Asset Overview - Asset Status: asset-overview-data.ts:20 (6 fixed values + extras from /ad/statuses).
 9. Asset Overview - "As of" options: html:14-17.
10. Asset Overview - category icons/colours: asset-overview-data.ts:12-19 (display only; categories come from API).
11. IoT - alert status actions (Acknowledged / In Progress / Resolved): html:250-252 (persisted via PATCH).

FILTERS THAT DO NOT REACH THE API (UI-only / no effect)
IoT & Tracking Overview:
12. Site/Asset Type/Status not sent to GET /ad/kpis -> 5 KPI cards ignore them (BE supports siteId/assetType/status).
13. Site/Asset Type/Status not sent to GET /ad/device-connectivity -> donut ignores them (BE supports them).
14. Period on Device Connectivity: FE sends days=, BE endpoint has no days param -> period has no effect.
15. Site/Asset Type/Status not sent to GET /ad/locations -> Top Active Sites ignores them (BE supports them).
16. Asset Quick View ignores all filters.
17. UI-only toggles: timeline series, map zoom/reset, Top Sites View All, alerts sort/View All/pager (client-side over
    max 500 rows from /ad/alerts?limit=500).
Asset Overview:
18. All 6 KPI cards ignore Site/Category/Type/Status (computed from unfiltered API totals).
19. Asset Portfolio by Category ignores all filters (GET /ad/categories has no filter params).
20. Asset Category filter: client-side only on every widget (no API accepts category).
21. Asset Status filter: client-side only (no API call takes it).
22. Site filter: client-side only except Health Distribution (siteId=); on the site map it only highlights.
23. Asset Type: client-side except Health Distribution and site map (assetType=).
24. Asset Status Overview, Quick Insights (4), Assets table, Lifecycle Aging: filtered client-side from full API lists
    (no filter params on /ad/statuses, critical-assets, assets-without-custodian, assets-without-documents,
    assets-due-maintenance, aging - although BE aging/assets-due-maintenance accept AssetDashboardFilter).
25. Health Distribution ignores Category and Status.
26. Site map ignores Site/Category/Status (highlight only).
27. Assets due for maintenance window fixed at 30 days (ts:118); KPI window fixed at 30 days (ts:62), no selector.
28. Asset Quick View ignores all filters; tabs, View All Sites/Show Map, table pager = UI-only.

WIRED BUT EMPTY ON DEV (REAL API, no data in Asset360Dev - not a code gap, listed for the demo)
29. IoT: all 5 KPIs (0), Device Connectivity, Firmware, Utilization, Events Timeline, Sensors Requiring Attention,
    Recent Alerts; Health Score (all Unknown); map has no coordinates.
30. Asset Overview: Avg Asset Health Score, Due for maintenance; Health Distribution (all Unknown); site map has no coordinates.
