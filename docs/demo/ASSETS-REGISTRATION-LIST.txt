CONNECTED (item -> route)
  Asset List
    Table rows, search, sort, pagination, status cards -> GET /api/asset-registrations (page, pageSize, search, sort; summary)
    Filters: category, type, status, location, department, custodian, criticality -> GET /api/asset-registrations/filters
    Export / Export selected (CSV, built in the browser) -> GET /api/asset-registrations (all matching)
    View Details -> /assets/overview?id= (asset detail page)
    Edit Asset -> /assets/registration?id= ; GET /api/asset-registrations/{id} + PUT /api/asset-registrations/{id}
    Delete Asset (NEW in UI; endpoint existed) -> DELETE /api/asset-registrations/{id} (soft delete)
    Assign/Transfer, Location History, Schedule Maintenance, Dispose -> open those modules (unchanged)
  Asset Registration
    Step 1 Basic: Status, and the fixed lists below -> GET /api/asset-registrations/options
                  Condition -> GET MD/conditions; Criticality -> GET MD/criticalities
                  Manufacturer, Model -> GET MD/manufacturers, MD/asset-models
                  Asset image upload -> POST /api/media/upload (category asset-images)
    Step 2 Classification: Category, Sub Category -> GET /api/asset-categories (?parentCategoryId=)
                  Asset Type -> GET /api/asset-category-types?categoryId=
                  Department -> MD/departments; Business Unit -> MD/business-units
                  Function/Purpose, Tagging Method, Compliance Category, Lifecycle Stage -> /options
    Step 3 Location: Country/Site/Building/Floor/Zone/Room -> MD/sites, buildings, floors, zones, locations (rooms)
                  Custodian Department -> MD/departments; Assigned To -> MD/employees (by department)
                  Responsible Team -> MD/teams; Ownership Type -> /options
                  Floor plan image -> MD/floors imageUrl
    Step 4 Purchase: Supplier/Vendor -> MD/suppliers; Manufacturer -> MD/manufacturers
                  Quantity unit, Currency, Payment Terms, Procurement Method, Warranty type/coverage -> /options
                  Purchase documents upload -> POST /api/media/upload (category asset-documents)
    Step 5 Additional: spec units, IP rating, fuel, phase, shifts, utilization, standards -> /options
                  Custom fields -> GET /api/asset-custom-fields?scope=Asset&status=Active
                  Attachments upload -> POST /api/media/upload
    Save as Draft / Next / Submit -> POST /api/asset-registrations/drafts, PUT .../drafts/{id}/{section}, POST .../drafts/{id}/submit
    Edit mode save -> PUT /api/asset-registrations/{id}
